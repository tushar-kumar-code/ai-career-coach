## 🌟 Overview

**AI Career Coach** is an intelligent, full-stack career guidance and placement-readiness platform built specifically for Computer Science students and freshers.

It addresses the core challenge every CS student faces: **knowing what to learn, how to present themselves, and whether they are actually ready for the job market.**

The platform integrates 13 connected modules — from career discovery and resume analysis to adaptive mock interviews and a real-time Career Digital Twin — into a single, coherent system driven by AI.

## 🎯 The Problem

Most students graduate without a clear answer to these questions:

| Problem | Reality |
|---|---|
| **Which career path is right for me?** | Thousands of options, no guidance |
| **Which skills am I actually missing?** | No structured gap analysis available |
| **Is my resume good enough?** | ATS systems filter resumes before a human ever sees them |
| **How do I prepare for interviews?** | Generic content, no personalized feedback |
| **Am I ready for placements?** | No objective readiness metric exists |
| **What should I learn next?** | Random tutorials without a prioritized roadmap |

---

## 💡 The Solution

AI Career Coach connects all of these problems into one end-to-end platform:

```
Career Discovery       →  understand your strengths & career fit
         ↓
Skill Gap Analysis     →  know exactly what you are missing
         ↓
Resume Intelligence    →  make your resume job-ready with ATS scoring
         ↓
Personalized Roadmap   →  structured, prioritized learning path
         ↓
Mock Interviews        →  prepare with real AI feedback per answer
         ↓
Job Intelligence       →  find and match jobs to your profile
         ↓
Placement Readiness    →  know your objective readiness score
```

Every module feeds real data into the next — your resume skills inform your roadmap, your roadmap feeds your interview prep, and your interview scores update your placement readiness.

## ✨ Key Features

| Module | What It Does |
|---|---|
| 🎯 **Career Discovery** | Multi-dimension adaptive assessment evaluates interests, work style, and strengths. AI engine matches to career archetypes and recommends best-fit roles. |
| 📄 **Resume Intelligence** | Upload PDF or DOCX resume. AI extracts content, computes ATS sub-scores across 5 dimensions, and matches your skills against your target career. |
| 🔢 **ATS Score** | Algorithmic ATS breakdown: formatting, keywords, skills, experience, and readability. Provides specific improvement guidance per dimension. |
| 🧠 **Skill Intelligence** | Tracks skills from multiple evidence sources — resume, assessment, interviews. Assigns confidence levels: Claimed, Supported, Verified. Calculates gap priority per skill. |
| 🗺️ **Personalized Roadmap** | AI generates a phased, week-by-week learning roadmap based on your target career and current skill gaps. Tracks daily focus tasks and overall progress. |
| 💼 **Job Intelligence** | Catalog-backed job search with AI-powered skill match analysis. Save jobs and track applications with a full status history pipeline. |
| 🎤 **Interview Intelligence** | Adaptive mock interview engine with multiple modes and difficulty levels. AI evaluates each answer with STAR analysis, scoring, and detailed per-answer feedback. |
| 💪 **Micro Practice Engine** | Short, focused practice sessions on specific skills and topics linked to your roadmap and interview history. |
| 🤖 **Career Digital Twin** | Real-time synchronized career profile. Computes sub-scores across skill, resume, interview, and roadmap dimensions. Tracks daily progress snapshots, achievements, and weekly career reports. |
| 📊 **Progress and Readiness** | Tracks overall placement readiness from a composite of all module signals. |
| 🎓 **Placement Readiness** | 10-point placement checklist evaluated from live DB evidence. Each item shows current value, target goal, and a 1-click remediation action. |
| 📋 **1-Page Career Brief** | Generates an executive career summary aggregating your profile, verified skills, ATS score, and interview readiness — for mentors, faculty, and placement cells. |
| 💬 **Conversational Career Coach** | Context-aware AI chat assistant that knows your profile, skills, resume score, and roadmap progress. Provides personalized guidance in natural language. |

## 🏗️ Architecture

```
+----------------------------------------------------------+
|                      Browser / Client                    |
|          Next.js 14  .  TypeScript  .  Tailwind CSS      |
|    13 dashboard routes . Auth pages . Chat interface     |
+-------------------------+--------------------------------+
                          |  HTTP / REST  (JWT Auth)
                          v
+----------------------------------------------------------+
|                   FastAPI Backend  (v1.0)                 |
|          12 API route groups . Async SQLAlchemy           |
|  auth . assessment . resume . skills . roadmap . jobs    |
|  interview . digital-twin . placement . chat . settings  |
+------------------+------------------+--------------------+
                   |                  |
                   v                  v
+------------------+    +-------------------------------+
|  PostgreSQL DB   |    |       AI Services Layer       |
|  (Supabase /     |    |   Groq LLM  |  Gemini API    |
|   SQLite local)  |    |  (default)  |  (alternative) |
|  10 migrations   |    |  Pluggable provider pattern   |
+------------------+    +-------------------------------+
```

**Key architectural decisions:**

- **Async throughout** — FastAPI + SQLAlchemy async + asyncpg for non-blocking I/O
- **Pluggable AI providers** — Provider abstraction layer supports Groq, Gemini, OpenAI, or Anthropic. Provider and API key are injected per-request via HTTP headers — no hard-coded lock-in
- **JWT authentication** — Custom JWT auth with python-jose; OTP-based login and password reset flow included
- **Alembic migrations** — Full database migration history with 10 versioned schema migrations
- **Monorepo structure** — Frontend and backend colocated but fully independent deployments

## 🔄 How It Works

A typical end-to-end user journey:

1. **Register and Login** — Create an account with email/password or use OTP-based login
2. **Career Discovery** — Complete an adaptive multi-dimension assessment; AI analyzes your answers and recommends career archetypes and specific roles
3. **Set Target Career** — Select your target role from AI recommendations or the career catalog
4. **Upload Resume** — System extracts text from PDF or DOCX, runs ATS scoring across 5 dimensions, and identifies matching and missing skills against your target career
5. **Skill Profile Built** — All skill evidence from resume, assessment, and interviews is aggregated with confidence levels: Claimed, Supported, and Verified
6. **Roadmap Generated** — AI creates a phased, week-by-week learning plan prioritized by your highest-impact skill gaps
7. **Interview Practice** — Adaptive mock sessions generate role-specific questions at your difficulty level; AI evaluates each answer with STAR analysis and a score
8. **Job Matching** — Browse catalog jobs; AI computes a skill match percentage and tracks your applications with status history
9. **Track Everything** — Career Digital Twin syncs all modules into one readiness score, tracks daily progress snapshots, and surfaces your next best action
10. **Placement Ready** — 10-point checklist shows exactly where you stand and what to fix before placements begin

## 🚀 Getting Started

### Prerequisites

| Tool | Version |
|---|---|
| Node.js | 18 or higher |
| Python | 3.11 or higher |
| npm | 9 or higher |
| Git | any |

> **AI API Key required.** You need at least one AI provider API key. Groq is recommended — free tier available at [console.groq.com](https://console.groq.com).

---

### 1. Clone the Repository

```bash
git clone https://github.com/tushar-kumar-code/ai-career-coach.git
cd ai-career-coach
```

---

### 2. Backend Setup

```bash
cd backend

# Create virtual environment
python -m venv venv

# Activate — Windows
.\venv\Scripts\activate

# Activate — macOS / Linux
source venv/bin/activate

# Install dependencies
pip install -r requirements.txt
```

**Configure environment variables:**

```bash
# Windows
copy .env.example .env

# macOS / Linux
cp .env.example .env
```

Open `backend/.env` and fill in your values. See the [Environment Variables](#-environment-variables) section for details.

**Apply database migrations:**

```bash
python -m alembic upgrade head
```

**Start the server:**

```bash
python -m uvicorn app.main:app --port 8000 --reload
```

| Service | URL |
|---|---|
| API Base | `http://127.0.0.1:8000/api/v1` |
| Swagger UI | `http://127.0.0.1:8000/docs` |
| Health Check | `http://127.0.0.1:8000/api/v1/health` |

---

### 3. Frontend Setup

Open a **second terminal**:

```bash
cd frontend

npm install

# Windows
copy .env.example .env.local

# macOS / Linux
cp .env.example .env.local
```

**Start the dev server:**

```bash
npm run dev
```

Open **[http://localhost:3000](http://localhost:3000)** in your browser.

## 🔒 Security

- All secrets, API keys, and credentials are managed through **environment variables** — never hardcoded
- `backend/.env` and `frontend/.env.local` are excluded from Git via `.gitignore`
- JWT tokens secure all authenticated API routes using `python-jose` with `bcrypt` password hashing
- AI API keys can be injected per-request via HTTP headers — `X-AI-API-Key`, `X-AI-Provider`, `X-AI-Model` — for flexible client-side key management
- `backend/.env.example` and `frontend/.env.example` contain only placeholder values. No real credentials are ever committed.
