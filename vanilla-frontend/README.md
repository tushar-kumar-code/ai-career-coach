# 🌐 AI Career Coach — Vanilla HTML, CSS & JavaScript Edition

Yeh folder **100% Pure Vanilla Web Technologies** me bana hua hai:
- **Structure**: 100% Pure HTML5 (`index.html`)
- **Styling**: 100% Pure CSS3 with Custom Variables & Glassmorphism (`styles.css`)
- **Logic & APIs**: 100% Pure Vanilla JavaScript ES6+ (`app.js`)
- **Backend**: 100% Pure Python FastAPI (`http://localhost:8000`)

## 🚀 Kaise Chalayein (How to Run)

### Option 1: Direct Browser Me Open Karein (Zero Setup)
1. Apne file explorer me jayein: `c:\Users\user\tushar\ai-career-coach\vanilla-frontend`
2. **`index.html`** file par double-click karein!
3. Yeh turant kisi bhi browser (Chrome, Edge, Firefox) me open ho jayega.

### Option 2: VS Code Live Server Se Run Karein
1. VS Code me `vanilla-frontend/index.html` file open karein.
2. Right click karke **"Open with Live Server"** par click karein.
3. Live URL: `http://127.0.0.1:5500/vanilla-frontend/index.html`
