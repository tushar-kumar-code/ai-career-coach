# Project Agent Guidelines

## Automatic Git Push Rule
- **Mandatory Git Push**: After completing ANY code updates, bug fixes, or enhancements in this repository, ALWAYS automatically stage, commit (with a clear, descriptive conventional commit message), and push the changes to GitHub (`origin main` under `tushar-kumar-code/ai-career-coach`).
- **No Explicit Prompt Needed**: Do this automatically on every update, whether the user explicitly asks to push or not.
- **Verification**: Always ensure local checks (builds/lints if applicable) pass before pushing.
